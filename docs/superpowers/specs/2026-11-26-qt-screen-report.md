## 만든 것

- **`qt/ui` (`xgsui`, 위젯 없음):** `AppStateHolder`(TS `holder.ts`를 옮김), `labels`, `SettingsStore`, `AppApi`, `EngineApi`(엔진의 막는 호출을 `std::jthread`에서 돌리고 답을 GUI 스레드로 넘김), 플레이리스트의 `PlaylistStore`·`mergeRemote`·`checkEntry`·`RemotePlaylists`.
- **`qt/app` (`xGetSongs.exe`):** `MainWindow`, `PlaylistsDialog`, `PlaylistEntryDialog`, `AboutDialog`, `SingleInstance`, `AppServices`(엔진·가사·숨은 WebView2 조립과 내리는 순서).
- `THIRD-PARTY-NOTICES.md`에 Qt(LGPLv3)·WebView2 SDK 고지와 LGPL-3.0·GPL-3.0 전문을 더했다(이미 있던 파일).
- 릴리스 `build/qt/xGetSongs.exe`: 22,608,896바이트.

## exe를 띄워 본 것 (2026-11-27, 사용자에게 알린 뒤 1회)

가짜 `APPDATA`·`LOCALAPPDATA`와 점검용 식별자(`XGS_CHECK_INSTANCE_ID`)로 릴리스 exe를 띄웠다. 사용자의 xGetSongs는 그때 떠 있지 않았다.

- 시작 뒤 약 1.8초에 제목 `xGetSongs`인 창이 생겼다(0.1초 간격으로 본 값).
- 3초 뒤 자식 프로세스 0개, 작업 집합 약 120MB.
- 닫기 요청 뒤 0.2초에 종료 코드 0으로 끝났고 남은 프로세스가 없었다. 가짜 폴더에 파일이 생기지 않았다.
- 아무 버튼도 누르지 않았다. **창의 모양은 보지 못했다**(창 그림을 찍는 코드가 실패했고, 한 번만 띄우기로 했으므로 다시 띄우지 않았다).

이 점검을 위해 `main.cpp`에 `XGS_CHECK_INSTANCE_ID` 환경 변수를 넣었다(값이 있으면 그 식별자를 쓴다). 설계 §3의 "점검 도구만 별도 식별자"를 위한 것이다.

## 확인하지 못한 것

- S5 전부와 창의 모양(간격, 100~200% 배율, 어두운 테마).
- 다운로드 중·구글 가사 조회 중에 닫았을 때의 실제 종료 시간과 남는 프로세스. 부품 단위 시험만 있다.
- Tauri 판과 Qt 판이 서로를 단일 인스턴스로 알아보는지. 플러그인 소스의 이름과 맞췄지만 두 앱을 실제로 띄워 보지 않았다.
- 출력 폴더가 다른 드라이브일 때의 작업 폴더 동작(실제 작업으로는 안 돌림).
- `QDesktopServices`로 탐색기를 열 때 실행기의 파이프 핸들이 물려지는지.
- 작업 2는 리뷰 없이 구현자 보고만 받았다. 작업 1·3의 수정분은 재리뷰하지 않았다. 전체 최종 리뷰는 하지 않았다.
- 대조 도구와 Q2의 동시성 exe는 다시 돌리지 않았다(Q3 뒤로 `qt/core`·`qt/webview`·`qt/tools/differential`에 변경 없음을 `git diff`로 확인).

## 사용자가 정할 것

1. 화면 문구의 "서버"("서버와의 연결이 끊어졌습니다." 등)를 Qt 판에 맞게 바꿀지.
2. `정보` 버튼의 자리(지금은 도구 카드 오른쪽 위).
3. WebView2가 없을 때 알림 없이 구글 가사만 빼는 것을 그대로 둘지.
4. 마지막 곡 직후의 취소가 `완료`로 보이는 것을 그대로 둘지.
5. 설정의 모르는 키를 남기는 것(설계서대로, Rust 판과 다름)을 그대로 둘지. 이 때문에 시험 `aConcurrencyFromAnOlderFileIsIgnoredAndLeftOutOfTheNextSave`는 이름과 달리 키가 남는지를 본다.
6. 새로 지은 문구(플레이리스트 대화상자, 정보 창, 설치 거절 문구)를 고칠지. 목록은 작업 보고서에 있다.
7. Q3에서 넘어온 것: 실제 구글 확인 1회, MSVC 한국어 출력 때문에 ninja가 헤더 변경을 놓치는 문제(`VSLANG=1033`을 프리셋에 넣을지). 이번에도 헤더 변경을 한 번 놓쳤다.

## Q5·Q6으로 넘길 것

- 로그 파일(`JobLog`, `GoogleLyricsLog`, 지금은 Qt 메시지 처리기로만 나감), 낡은 작업 폴더 정리, 멈춤 감시.
- exe의 아이콘과 버전 리소스(아이콘은 `shell/` 아래에만 있다).
- Qt에 들어 있는 라이브러리(FreeType, HarfBuzz, libpng 등)의 고지 전문.
- `EngineApi`가 받기만 하고 쓰지 않는 `ProcessRunner&`와 `tempRoot` 정리.
